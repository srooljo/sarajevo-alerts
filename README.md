# Status Šehera

Tracks electricity, water, heating and major traffic disruptions in Sarajevo
Canton and sends a push notification when a new notice mentions one of the
owner's watched streets, neighbourhoods or municipalities.

- `fetch.py` — scheduled job (every 30 min). Collects EPBiH planned power cuts,
  ViK water works, GRAS public-transport changes, BIHAMK road conditions,
  Toplane (when reachable) and Klix/N1/FENA/Avaz news; writes `events.json`,
  `streets.json` (street → municipality, learned from EPBiH),
  `street-names.json`, `notified.json`, `cache.json`; reads `watch.json`.
  Preview safely with `python3 fetch.py --dry-run --watch watch.json`
  (writes ./events.json, never notifies).
- `index.jsx` — notices list with type filters, My places editor.
- `domain.js` — matching mirrored from `fetch.py`.
- `hoods.json` / `hoods.js` — street → municipality → neighbourhoods (mjesne
  zajednice where OSM has boundaries, else nearest named neighbourhood),
  generated by `build_hoods.py` from OpenStreetMap (© OpenStreetMap
  contributors, ODbL). The job labels each notice with `hoods`; watching a
  neighbourhood name (e.g. "Hrasno") matches notices labelled with it.
